Zásady ochrany soukromí

Platné od 18. 11. 2026 pro aplikaci Pošta.

Kdo aplikaci provozuje

Pošta je osobní aplikace, kterou si její autor provozuje sám pro sebe na vlastním počítači. Nejde o veřejnou službu a nemá jiné uživatele.

Jaká data aplikace používá

Po výslovném svolení uživatele aplikace přistupuje k jeho Google Disku, aby mohla zobrazit seznam souborů, soubory stáhnout, nahrát, vytvořit složku nebo přesunout soubor do koše. Vše se děje jen na pokyn uživatele.

Jak se data ukládají

Obsah souborů z Google Disku aplikace neukládá. Ukládá pouze přístupový token od Googlu, a to zašifrovaně na počítači uživatele. Žádná data se neposílají nikomu dalšímu, neprodávají se a nepoužívají se k reklamě ani k trénování modelů umělé inteligence.

Využití dat z Google API

Používání a přenos informací získaných z Google API se řídí zásadami Google API Services User Data Policy, včetně požadavků Limited Use.

Jak přístup zrušit

Přístup lze kdykoli odebrat v aplikaci (Google Disk → Nastavení → Odpojit), nebo na stránce oprávnění účtu Google. Tím se uložený token zneplatní.
